# Personal Profile Card

A simple, responsive profile card built using plain HTML and CSS — no frameworks, no JavaScript. Built as a foundational project to strengthen core CSS concepts: the box model, flexbox layout, selectors, and pseudo-classes.

## 🔗 Live Preview
Open `index.html` directly in any browser — no build step or server required.

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox)

## ✨ Features
- Fully responsive centering using Flexbox
- Circular profile image with `object-fit: cover` for proper cropping
- Custom box-shadow for a soft card elevation effect
- Interactive button states (`:hover`, `:active`)
- Clean CSS reset using the universal selector

## 📚 Concepts Practiced
- Box model (`margin`, `padding`, `border-box`)
- Flexbox (`justify-content`, `align-items`, `flex-direction`)
- CSS selectors (universal, element, class, descendant, compound)
- Pseudo-classes (`:hover`, `:active`)
- `rgba()` colors and `box-shadow`
